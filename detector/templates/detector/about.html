About the model

PneumoDetect AI fine-tunes a pretrained ResNet-18 to sort chest X-rays into four classes: COVID19, NORMAL, PNEUMONIA and TUBERCULOSIS. It is a learning project, built to demonstrate transfer learning and honest model evaluation.

Dataset

Chest X-Ray (Pneumonia, Covid-19, Tuberculosis) on Kaggle, with Train / Test / Val folders and one sub-folder per class: COVID19, NORMAL, PNEUMONIA and TUBERCULOSIS. The exact number of images per class in the training and validation splits is printed in the training log, and the test set size is shown on the Performance page.

The classes are imbalanced: PNEUMONIA is the largest group and COVID19 and TUBERCULOSIS are much smaller, so class weights are used during training. The dataset combines images from several public sources (for example, tuberculosis images are described as coming from a separate public TB database), so the groups may differ in more than the disease (see Limitations).

Preprocessing and augmentation

  • All images: converted to 3-channel grayscale, resized to 224×224, scaled to [0, 1] and normalised with ImageNet mean and standard deviation (what the pretrained network expects). Uploads in this app go through exactly this pipeline.
  • Training images only: random horizontal flip, random rotation up to 10°, and brightness jitter (0.2). Validation and test images are never augmented.

Architecture

ResNet-18 with ImageNet-pretrained weights. The original 1000-class output layer is replaced by a new linear layer (512 → 4). The pretrained layers act as a feature extractor, which is the core idea of transfer learning.

Training and validation

  • A stratified 80/20 split of the training folder (fixed random seed, same class mix in both parts) is used for validation; the dataset’s own Val folder is not used.
  • Loss: cross-entropy with class weights to offset the class imbalance.
  • Phase 1: backbone frozen, only the new final layer trained (Adam, learning rate 1e-3, 5 epochs).
  • Phase 2: the last residual block (layer4) unfrozen and fine-tuned with the final layer (Adam, learning rate 1e-4, 5 epochs).
  • The checkpoint with the lowest validation loss was kept.
  • The test set was used once for the final metrics shown on the Performance page.

Shortcut learning

In the earlier two-class version of this project, Grad-CAM heatmaps showed the model often looking at image corners, borders and text markers instead of the lungs, which suggests it partly relied on dataset-specific artifacts. That check has not yet been repeated for this four-class model. The concern is probably larger here: if the COVID19 and TUBERCULOSIS images were collected from different sources than the others, the model could learn the source (machine, crop, markers) rather than the disease.

Limitations and intended use

  • Educational use only. Not a medical device, not clinically validated, and not a diagnosis.
  • Trained on one public dataset; performance on other populations, hospitals or X-ray machines is unknown.
  • The test set is limited in size, and the COVID19 and TUBERCULOSIS classes are small, so their scores can change a lot with different data.
  • The PNEUMONIA class is one group; the model is not asked to tell bacterial from viral pneumonia, and COVID-19 can itself cause pneumonia, and pneumonia and tuberculosis can look alike on a chest X-ray.
  • The percentage shown for a prediction is the model’s softmax output. It is not the probability that a person has COVID-19, pneumonia or tuberculosis, and such scores are often overconfident.
  • The model does not check that an uploaded image is a chest X-ray.
